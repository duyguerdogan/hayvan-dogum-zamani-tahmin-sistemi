# Model dosyaları

Eğitim notebook’unu çalıştırdıktan sonra üretilen `scaler.pkl`, `rf_model.pkl`, `xgb_model.pkl` ve `mlp_model.pkl` dosyalarını bu dizine kopyalayın. Bu dosyalar depoya dahil değildir. API bu dört dosyayı kullanır; notebook’un ürettiği LSTM dosyasını yüklemez. Eğitim ve çıkarım ortamlarındaki kütüphane sürümlerinin uyumlu olması gerekir. Yalnızca kendinizin ürettiği veya güvendiğiniz model dosyalarını yükleyin.
